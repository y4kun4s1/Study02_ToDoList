# Study02_ToDoList

브라우저에서 바로 실행되는 개인용 할 일 관리 앱의 기획 문서(PRD) 저장소입니다.

## 소개

하루 10~20개 정도의 할 일을 관리하는 개인용 웹 앱입니다. 서버나 로그인 없이 브라우저에서 열기만 하면 되고, 새로고침해도 데이터가 유지됩니다.

## 주요 기능

- 할 일 추가 / 수정 / 삭제
- 완료 체크
- 카테고리 분류 (업무 / 개인 / 공부)
- 진행률 보기 (전체 및 카테고리별)
- `localStorage` 기반 데이터 유지

## 기술 스택

- HTML, CSS, 순수 JavaScript (프레임워크·라이브러리 없음)

## 문서

- [PRD.md](PRD.md) — 제품 요구사항 문서 (기능 요구사항, 데이터 모델, 화면 구성, 수용 기준, 마일스톤)
