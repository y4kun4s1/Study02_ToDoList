# Study02_ToDoList

브라우저에서 바로 실행되는 개인용 할 일 관리 앱입니다.

## 소개

하루 10~20개 정도의 할 일을 관리하는 개인용 웹 앱입니다. 서버나 로그인 없이 브라우저에서 열기만 하면 되고, 새로고침해도 데이터가 유지됩니다.

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. 설치나 빌드는 필요 없습니다.

## 주요 기능

- 할 일 추가 / 수정 / 삭제
- 완료 체크 (취소선 표시)
- 카테고리 분류 (업무 / 개인 / 공부)와 카테고리 필터
- 진행률 보기 (전체 및 카테고리별)
- `localStorage` 기반 데이터 유지

## 사용법

- **추가**: 입력창에 내용을 쓰고 카테고리를 고른 뒤 Enter 또는 `추가` 버튼
- **완료**: 항목 왼쪽 체크박스
- **수정**: 텍스트를 더블클릭하거나 ✎ 버튼. Enter 또는 포커스 이동으로 저장, Esc로 취소
- **삭제**: 🗑 버튼 (확인 창 표시)
- **필터**: 상단 탭 (전체 / 업무 / 개인 / 공부). 진행률은 필터와 상관없이 전체 기준

## 기술 스택

- HTML, CSS, 순수 JavaScript (프레임워크·라이브러리 없음)
- 데이터는 `localStorage`의 `todoApp.v1` 키에 JSON으로 저장
